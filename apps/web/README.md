# @pipetwin/web — демо-интерфейс

**Владелец:** C. Подробно — ТЗ, раздел 12, WP-C4…C6, C8, C9.

Vite + TypeScript, Canvas 2D или SVG, графики uPlot. Расчёт — в Web Worker: `DataSource`, twin и детектор; в основном потоке — только отрисовка.

## Контракты

- Использует: `PipelineConfig`, `DataSource`, `TwinPrediction`, `DetectorOutput`, `EventCard`, `GroundTruth` (только для секундомера и маркера истинного места — в воркер детектора не передаётся).
- Читает: `configs/strategy.selected.json` (стратегия по умолчанию), `configs/pipeline.*.json`.
- Пишет: журнал демо (CSV), экспорт сессии как `Scenario`.

## Экраны (план)

Схема трубы из конфига, клик-утечка и ползунок размера, секундомер с физическим минимумом, графики «замер и прогноз» и невязки с порогом, панель режима (насос, задвижка, шум), панель статусов параметров, журнал сообщений детектора, карточка события, мастер маппинга, форма параметров из схемы.

Отчёт по гипотезам H-C1…H-C6 — в этом файле, в конце недели.
