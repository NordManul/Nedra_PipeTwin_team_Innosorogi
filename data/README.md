# data/

Сюда кладём ресурсы организаторов как есть: паспорта труб, записи датчиков, описания, их симуляторы. Файлы не правим — из них импорт (`packages/io`) делает конфиги в `configs/` и нормализованные кадры.

Рекомендуемая раскладка: `data/<источник>/<дата>/…` и рядом `README.md` с описанием, откуда файл и что в нём.

Большие или закрытые файлы в git не кладём — только описание и ссылку.
