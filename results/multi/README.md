# Стенд нескольких утечек (H-B15)

230 сценариев на 50-км трубе с настройками по умолчанию (выбранная стратегия EWMA, пороги на 1 ложную тревогу
в сутки, ML-локатор). Детектор видит только кадры датчиков; правда — места, время начала и снятия — у стенда.
Сценарии детерминированы (зерно 20261103), шум датчиков 0,1–0,3%, утечки 3, 5, 8 и 12% расхода.

| Набор | Что происходит |
| --- | --- |
| Одновременные пары (70) | две утечки начинаются с разницей 0–5 с, не ближе 8 км; на 600 с снимают первую, на 800 с — вторую |
| 2–3 подряд, снятие частями (60) | новая утечка каждые 5–6 мин; через 6 мин после последней снимают случайную часть, ещё через 5 мин — остальные |
| 2–3 подряд, снятие всех сразу (40) | то же, но все снимают одновременно |
| Одиночные (40) | контроль: одна утечка 2–20% не должна делиться на две |
| Без утечек (20) | 20 минут со сменами режима насоса и задвижки: не должно быть ни одной тревоги |

Одновременные пары: между утечками есть датчик давления — разделено 87% (54/62); обе между одними датчиками — 0% (0/8).
По размеру меньшей утечки пары: 3% — 85% (22/26), 5% — 82% (14/17), 8% — 94% (16/17), 12% — 100% (2/2).

## Как считаются метрики

- **Найдена** — до первого снятия (или к концу прогона) есть активная утечка, чья зона содержит истинное место.
- **Пара разделена** — обе одновременные утечки найдены разными записями.
- **Снятие распознано** — через 240 с после снятия активных записей столько же, сколько действующих утечек,
  и каждая действующая покрыта зоной; время — до первого такого момента.
- **Секунд с фантомом** — сумма по сценариям времени, когда есть активная запись, не покрывающая ни одной
  действующей утечки (обычно — остаток после неверно распознанного снятия, пока он не снимется сам).
- **Итог верный** — к концу прогона активных записей нет (все утечки сняты, система вернулась в норму).

## Что видно

- Утечки подряд и снятие частями или всех сразу система распознаёт в 95–98% случаев, за ~2 минуты;
  к концу прогона в норму возвращается 88–98% сценариев.
- Две одновременные утечки делятся, если между ними есть датчик давления (87%): волны приходят на датчики
  в разном порядке, и одним источником это не объяснить. Две утечки между одними датчиками дают почти
  одинаковый отклик на всех датчиках — их система видит как одну (зона охватывает обе), это физический предел
  расстановки датчиков, а не настройки.
- Одиночная утечка ложно делится на две в 1 случае из 40, её снятие распознаётся во всех 40; в прогонах без утечек
  со сменами режима — 0 тревог.

## Запуск

```bash
for i in 0 1 2 3; do npx tsx scripts/bench-multi.ts run --shard $i/4 --out results/multi/runs-$i.jsonl & done; wait
```

```bash
npx tsx scripts/bench-multi.ts report --in 'results/multi/runs-*.jsonl'
```

Вторая печатает таблицы раздела «Результаты» (с `--out <файл>` — пишет их в файл); прогоны (`runs-*.jsonl`) в репозиторий не кладутся.
Полный прогон — около 20 минут на 4 ядрах.
