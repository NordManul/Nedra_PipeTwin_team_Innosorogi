# Гипотезы по физике (H-A1…H-A7)

Измерения воспроизводятся командами `npx tsx scripts/hypotheses-physics.ts`, `npm run perf`, `python3 python/reference/compare_ts_py.py` и тестами `packages/core/test`. Труба — `configs/pipeline.default.json` (50 км, Ø530×8, лёгкая нефть 60 °C); «настоящая» труба отличается шероховатостью (0,08 мм против 0,05 мм у twin).

| ID | Гипотеза | Результат | Решение |
| --- | --- | --- | --- |
| H-A1 | Нужна нестационарная модель | Стационарный twin: ложная тревога в каждом из 3 прогонов «насос +10% → задвижка 60%», утечка 5% — за 27,0–27,6 с. Нестационарный (MOC по граничным давлениям): 0 ложных тревог, утечка 5% — за 2,7–14,7 с | **Да.** Plant — MOC; twin по умолчанию тоже нестационарный (`twin.model: "transient"`), стационарный — запасной вариант при отсутствии датчиков на концах |
| H-A2 | Явная формула трения достаточно точна и в 10 раз быстрее Коулбрука | Ошибка λ при Re 10³–10⁷, ε/D 10⁻⁶–10⁻²: Свами–Джейн до 6,7%, Хааланд до 5,6% (в турбулентной области ТЗ просит 2% — выполнено только при Re = 10⁵, T-A03). Время вызова: Коулбрук 253 нс, Свами–Джейн 216 нс, Хааланд 197 нс | **Нет**: выигрыша в скорости нет (Ньютон от Хааланда сходится за 2–3 шага). Коулбрук везде; в горячем цикле MOC λ кэшируется по отрезкам с линеаризацией по Re — это дало ускорение в 3–4 раза |
| H-A3 | Вязкость от температуры меняет прогноз сильнее шума | Прогноз давления на км 25 с учётом тепла и без отличается на 9,6 кПа = 0,8σ шума датчика (twin ведётся давлениями на концах, поэтому промежуточные давления к вязкости малочувствительны; расходы — чувствительнее) | **Почти**: эффект порядка шума, учёт стоит дёшево — тепло в twin включено (`quasi-steady`), датчики T полезны (через них k определяется надёжнее, T-A15/T-A16) |
| H-A4 | По p_вх, p_вых, Q_вх, T_вх, T_вых определяются ε и k | На трубе по умолчанию: ε и k из старта 0,2 мм и 5 Вт/(м²·К) сходятся к истине в пределах 5% (T-A15), ранг якобиана 2. Без датчиков T: k определяется косвенно через вязкость (1,8 ± 0,19 при истине 2); при вязкости, не зависящей от T, — помечается «не определяется» (T-A16). На 100 случайных трубах не проверялось | **Да** для трубы по умолчанию: калибруем оба; при плохой идентифицируемости калибровка сама оставляет параметр `default` с предупреждением |
| H-A5 | Twin без расходомера прогнозирует промежуточные давления точнее шума | Только давления на концах: невязка на км 25 — смещение −0,09σ, разброс 1,27σ шума датчика (вклад шума граничных датчиков) | **Да**: расходомеры необязательны; D1–D3, D5, D8, D9 работают без них, D4 и D6 выбывают по требованиям |
| H-A6 | Онлайн-подстройка не «съедает» утечку | Подстройка смещений невязки (τ = 120 с) в предобработке замораживается при подозрении (score > 0,5 порога) и на всё время тревоги; в T-B13/T-B18 тревога держится до конца прогона | **Да**: режим «с заморозкой» по умолчанию. Калибровка параметров трубы — по запросу на окне без утечки |
| H-A7 | 2000 узлов укладываются в 2 мс на шаг | Node: шаг plant + прогноз twin — 0,23 мс (500 узлов), 0,59 мс (1000), 1,81 мс (2000). В Chrome отдельно не профилировалось; интерфейс на 500 узлах работает на ×20 без задержек | **Да** (в Node). Сетка по умолчанию — Δx ≈ 100 м, от 50 до 1000 отрезков (`defaultGridStep`) |

## Сверка с эталоном (T-A19)

TS-ядро против SciPy (`solve_ivp`, непрерывная ОДУ) на 5 конфигах: расхождение давления ≤ 0,09% перепада (тяжёлая нефть в ламинарном режиме — самое большое), температуры — < 0,001 К.
