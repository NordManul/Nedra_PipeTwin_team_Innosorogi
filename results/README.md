# results/

Результаты экспериментов. Воспроизводятся командами `npm run bench` и `npm run select`.

| Путь | Что | В git |
| --- | --- | --- |
| `leaderboard.md` | Лидерборд стратегий: метрики, фильтры, счёт, выбор и почему | да |
| `report.html` | Графики «TTD от размера утечки», «TTD против FAR» — для слайдов | да |
| `strategies.tuned.json` | Пороги после калибровки на валидационных seed | да |
| `excluded.csv` | Какие детекторы выбыли по требованиям к датчикам и почему | да |
| `physics/README.md` | Гипотезы H-A1…H-A7: гипотеза — результат — решение | да |
| `detection/README.md` | Гипотезы H-B1…H-B9 | да |
| `runs.csv` | Строка на пару «сценарий × стратегия» ([формат](../docs/contracts.md#12-результат-прогона--runscsv)) | нет, воспроизводится стендом |
| `cache/` | Кэш стенда по хэшу сценария и стратегий | нет |
