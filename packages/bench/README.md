# @pipetwin/bench — стенд экспериментов

Тот же код ядра и детекторов, что в браузере, но в Node: сотни сценариев параллельно. ТЗ, разделы 11, 13, 14.

```bash
npm run bench                          # полная матрица
npm run bench -- --quick               # < 1 мин
npm run bench -- --suite e3,e4,e5,e6,random,noleak,files --config configs/pipeline.X.json --workers 3
npm run select                         # выбор стратегии
```

## Шаги

1. **Калибровка порогов** на валидационных seed (прогоны без утечки): максимумы статистики по минутным блокам → распределение Гумбеля → порог под `targetFarPerDay` из `configs/selection.json`. Детекторы с тревогой по шаблону (D5) — подсчётом тревог. Результат — `results/strategies.tuned.json`.
2. **Прогоны тестовых seed** с зафиксированными порогами → `results/runs.csv` (контракт `RunRecord`), выбывшие по требованиям → `results/excluded.csv`.
3. **Выбор** — `python/analysis/select_strategy.py`.

## Наборы сценариев (`src/scenarios.ts`)

| Набор | Что | ТЗ |
| --- | --- | --- |
| `e3` | Размер 0,5–20% × место 0,1–0,9 L × шум 0,1–0,5% × нарастание 0/30 с × seed | E3 |
| `e4` | 3/5/10 датчиков давления × 1/10/50 Гц | E4 |
| `e5` | Насос ±10%, задвижка, сочетания — без утечки и с утечкой на фоне события | E5 |
| `e6` | Шероховатость ±20%, вязкость ±15%, дрейф датчика | E6 |
| `random` | Случайные трубы: L 5–200 км, D 0,2–1,2 м, ν 1–300 сСт, 3–10 датчиков, шум 0,1–1% | раздел 14 |
| `noleak` | Длинные прогоны без утечки — знаменатель FAR | раздел 13 |
| `files` | Сценарии из `configs/scenarios/*.json`, включая replay и наложение утечки | WP-B6 |

## Устройство

- `runner.ts` — один сценарий × все стратегии: источник и twin считаются один раз, кадры подаются всем детекторам.
- `pool.ts` — `worker_threads`, кэш по хэшу (сценарий + стратегии + `BENCH_VERSION`) в `results/cache/`: прерванный прогон продолжается.
- `overlay.ts` — наложение утечки на запись без утечки через отклик twin с задержкой прихода волны (H-B9, T-B16).
- `metrics.ts` — TTD, POD, MDL, FAR, LOC, CPU, V_loss (сводка в консоли; выбор — в Python).

## Тесты

`test/bench.test.ts`: генераторы (схема, уникальные id), T-B15 (воспроизводимость), T-B16 (наложение в пределах 20% от симуляции).
