# @pipetwin/detect — детекция утечки

Детекторы, не зависящие от единиц, частоты опроса и конкретной трубы: параметры — в долях σ и секундах. ТЗ, раздел 11. Пакет не импортирует plant (проверка `npm run check:boundaries`).

## Как устроено

`DetectionPipeline` реализует контракт `Detector` для любой стратегии из `strategy.selected.json`:

```
кадр + прогноз twin
  → предобработка: сетка 0,1 с, пропуски, отсев выбросов, σ и μ невязки (заморозка при подозрении), z, знак утечки
  → статистика детектора (D1…D9)
  → защита от переходного режима: скачок на конце трубы (насос, задвижка) → порог ×1,5 на 1,5 пробега волны
  → монитор отказов: один датчик против всех дольше пробега до соседа → «отказ датчика», датчик исключается
  → сигнатура при тревоге: кто изменился первым (вход — насос, выход — задвижка, середина — утечка)
  → место: L3 по времени прихода волны сразу, L2/L1 после затухания волн
  → DetectorOutput
```

## Детекторы (`src/registry.ts`)

| Код | Имя | Метод | Требует |
| --- | --- | --- | --- |
| D1 | `threshold` | Порог на скользящем среднем z | давление, twin |
| D2 | `cusum` | CUSUM Пейджа по каналам и суммарному каналу | давление, twin |
| D3 | `ewma` | EWMA-карта | давление, twin |
| D4 | `mass-balance` | Баланс массы с поправкой на аккумуляцию | расход на обоих концах |
| D5 | `npw` | Волна отрицательного давления по паре датчиков | ≥ 2 давления, ≥ 5 Гц |
| D6 | `kalman` | Банк фильтров Калмана по местам утечки | ≥ 2 давления, расход, twin |
| D7 | `fusion` | Голосование / взвешенная сумма участников | по участникам |
| D8 | `rls` | Взаимное предсказание датчиков (без физики) | ≥ 3 датчика |
| D9 | `pca` | PCA и SPE (без физики) | ≥ 3 датчика |

Суммарный канал `__sum` — согласованный фильтр: невязки взвешены по отклику twin на утечку.

## Как добавить детектор за 15 минут

1. Класс в `src/detectors/`, реализующий `Statistic` (`update(sample): StatOut`, `rearm()`); на входе — `PreparedSample` с `z`, `e` (знак утечки), сырыми замерами.
2. Запись в `REGISTRY`: `code`, `title`, `requires`, `defaults` (σ и секунды), `thresholdParam`, `simplicity`, `create`.
3. Готово: стенд, интерфейс и `select_strategy.py` увидят его по имени; порог откалибрует стенд.
