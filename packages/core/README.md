# @pipetwin/core — физика и цифровой двойник

**Владелец:** A. Подробно — ТЗ, раздел 10.

Ядро на TypeScript без зависимостей от DOM: работает и в браузере (воркер), и в Node-стенде.

## Контракты

[`src/contracts.ts`](src/contracts.ts) — типы обмена между всеми модулями. Импорт из других пакетов — только так:

```ts
import type { SensorFrame, TwinPrediction, Detector } from '@pipetwin/core/contracts';
```

Описание — [docs/contracts.md](../../docs/contracts.md). Изменения — отдельным коммитом `contracts:` по правилам из п. 3.6.

## Модули (план)

| Модуль | WP | Что |
| --- | --- | --- |
| `src/units.ts` | A1 | Парсер величин из строк («1,2 МПа», «60 °C»), таблица единиц |
| `src/config/` | A1 | zod-схема, библиотека значений по умолчанию, `resolveConfig` |
| `src/fluid/` | A2 | `FluidModel`: плотность и вязкость от температуры |
| `src/friction.ts` | A3 | 64/Re, Коулбрук–Уайт, Свами–Джейн, Хааланд, переходная зона |
| `src/twin/` | A4 | Стационарный twin (RK4), три режима граничных условий, чувствительности |
| `src/plant/` | A5, A6 | Нестационарный plant (MOC), утечки, насос, задвижка, тепло |
| `src/sensors/` | A7 | Модель датчиков: шум, запаздывание, дрейф, квантование, сбои; ГПСЧ с seed |
| `src/calibrate/` | A8 | Калибровка по окну без утечки, отчёт об идентифицируемости |

**Граница:** `src/plant/**` — зона правды. Из `packages/detect` её импортировать нельзя (проверка в CI).
