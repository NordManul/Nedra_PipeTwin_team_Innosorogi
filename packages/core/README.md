# @pipetwin/core — физика и цифровой двойник

Ядро на TypeScript без зависимостей от DOM: один код для браузера (воркеры) и Node (стенд). ТЗ, раздел 10.

## Как создать конфиг трубы

Минимум — длина и диаметр, остальное из библиотеки со статусом `default`:

```ts
import { resolveConfig } from '@pipetwin/core';
const { config, params, calibrationCandidates } = resolveConfig({ schemaVersion: 1, geometry: { length: '30 км', diameter: '0,4 м' } });
```

Полный пример с единицами и статусами — [configs/pipeline.example.json](../../configs/pipeline.example.json). Ошибки называют поле и причину (`ConfigError.issues`).

## Модели

- **Twin по умолчанию нестационарный**, если на концах есть датчики давления (или расхода): повторяет волны от насоса и задвижки, поэтому смена режима не даёт невязки. Прогноз учитывает инерцию датчиков. Стационарный — `twin.model: "steady"`.
- **Plant**: метод характеристик, Δt = Δx/a; свойства отрезка — по левому узлу, как в стационарном расчёте, поэтому plant стартует без паразитных волн. Утечка — истечение через отверстие, решается вместе с характеристиками. Давление ниже давления паров ограничивается с предупреждением.
- **Тепло** (`numerics.thermalMode`): `none`, `quasi-steady` (Шухов по текущим расходам), `advection` (перенос по потоку с потерями).
- **Трение в горячем цикле**: λ кэшируется по отрезкам с линеаризацией по Re (ошибка < 1e-4) — шаг plant + twin < 0,6 мс на 1000 узлов (T-A20).

## Калибровка

```ts
import { calibrate } from '@pipetwin/core';
const r = calibrate(frames, resolved, { unknowns: ['geometry.roughness', 'thermal.heatTransferCoef', 'sensors.p_km10.bias'], window: [0, 300] });
// r.params: calibrated (с σ) или default с предупреждением «не определяется»; r.identifiability: ранг, обусловленность
```

Окно должно быть без утечки. Онлайн-подстройка смещений идёт в предобработке детектора и замораживается при подозрении на утечку (H-A6).
