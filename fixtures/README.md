| --- | --- | --- |
| `frames.example.csv` | Нормализованные кадры датчиков: `t` + колонки по `id`, СИ, давление абсолютное. 100 строк, 10 Гц, установившийся режим `pipeline.default.json` с шумом; в строке `t = 5.0` пропуск `p_km25` (пустая ячейка) | [contracts.md, п. 5](../docs/contracts.md#5-sensorframe--показания-датчиков) |
| `runs.example.csv` | Результаты прогонов стенда: пойманная утечка, пропущенная, прогон без утечки. Цифры условные — это формат, не результат | [contracts.md, п. 12](../docs/contracts.md#12-результат-прогона--runscsv) |
| `import/` | Чужие файлы для тестов импорта (T-C01…T-C09): по одному на каждую «неприятность» из WP-C1 | [import/README.md](import/README.md) |
