# fixtures/import/

Образцы «чужих» файлов для тестов `packages/io` (T-C01…T-C07). Собирает C. На каждую трудность WP-C1 — отдельный файл:

- CSV в cp1251, разделитель `;`, десятичная запятая;
- служебные строки над таблицей и строка единиц под заголовком;
- Excel с несколькими листами и объединёнными ячейками в шапке;
- разные форматы времени: ISO, `dd.mm.yyyy HH:MM:SS(.fff)`, unix в с и мс, дата Excel, дата и время в разных колонках;
- тэги КИП в именах колонок (PT-101, FT-201, TT-301);
- JSON — массив записей и колоночный формат.

К каждому образцу — ожидаемый результат (профиль маппинга и/или нормализованный CSV), чтобы тест сравнивал с ним.
