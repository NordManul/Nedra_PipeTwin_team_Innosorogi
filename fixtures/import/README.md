# fixtures/import/

Образцы «чужих» файлов для тестов `packages/io` (T-C01…T-C09). Генерируются из одних и тех же 30 кадров симулятора:

```bash
npm run fixtures
```

| Файл | Трудность |
| --- | --- |
| `scada_cp1251.csv` | cp1251, «;», десятичная запятая, 3 служебные строки, строка единиц, дата и время в разных колонках (Москва), тэги КИП, пропуск значения, лишняя колонка «Примечание» |
| `iso_utf8.csv` | ISO-время UTC, «,», заголовки с единицами в кавычках («P_вх, МПа») |
| `unix_ms.tsv` | Табуляция, unix-время в мс, давление в барах в квадратных скобках |
| `excel_serial.csv` | Время — дата Excel |
| `multi_sheet.xlsx` | Данные на втором листе, объединённая ячейка над таблицей, строка единиц (записан нашим `writeXlsx`) |
| `multi_sheet_sheetjs.xlsx` | Тот же лист, записанный SheetJS (другой стиль XML: строки формул `t="str"`, тема, стили, метаданные) — сохранён, не перегенерируется |
| `records.json`, `columns.json` | JSON: массив записей и колоночный формат |
| `passport.csv` | Паспорт трубы «параметр — значение — единица» |
| `expected.human.json` | Ожидаемые значения (МПа изб., м³/ч, °C) для сверки |
